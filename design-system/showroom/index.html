Wizard Workflow - Vertical

Stacked panel workflow. Only the current step is expanded. Completed steps collapse with summary and can be re-expanded for editing. Future steps are disabled. Supports error, optional, and 8+ steps.

4 steps — interactive

Click "Edit" on a completed step to re-expand it. "Continue" advances and marks the current step as completed; future steps remain disabled. Completed steps keep their state when navigating back.

8+ steps — scroll + optional + error

How To

Integration guides for different frameworks and environments.

Import (CSS)

Three ways to import the design system into your project.

Method 1: Copy the files
cp -r design-system/styles/ your-project/styles/design-system/ /* your-styles.css */ @import "./styles/design-system/index.css";
Method 2: Relative path (monorepo)
/* your-styles.css */ @import "../design-system/styles/index.css";
Method 3: npm link (local development)
cd design-system && npm link cd your-project && npm link design-system /* your-styles.css */ @import "design-system/styles/index.css";

Angular

Import the design system in an Angular project.

1. Import in your global stylesheet
/* src/styles.css */ @import "../../design-system/styles/index.css";
2. Set the theme in index.html
<!-- src/index.html --> <html data-theme="nord">
3. Switch themes at runtime
// In any component this.document.documentElement.setAttribute('data-theme', 'malo-1');
4. Use in templates
<!-- Tailwind arbitrary values --> <div class="bg-[var(--portal-bg-surface)] text-[var(--portal-text-primary)]"> Themed content </div> <!-- Or design system classes --> <button class="ds-btn ds-btn-primary">Click me</button>

React / Vite

Import the design system in a React or Vite project.

1. Import in your entry point
/* src/main.tsx or src/App.tsx */ import '../design-system/styles/index.css';
2. Set the theme in index.html
<!-- index.html --> <html data-theme="nord">
3. Switch themes at runtime
document.documentElement.setAttribute('data-theme', 'malo-1'); // Or with React state const [theme, setTheme] = useState('dark-slate'); useEffect(() => { document.documentElement.setAttribute('data-theme', theme); }, [theme]);
4. Use in components
function Card() { return ( <div className="bg-[var(--portal-bg-surface)] text-[var(--portal-text-primary)]"> Themed content </div> ); }

Plain HTML

Use the design system without any build tools.

1. Link the stylesheet
<link rel="stylesheet" href="design-system/styles/index.css">
2. Set the theme
<html data-theme="nord">
3. Switch themes with JavaScript
<select onchange="document.documentElement.setAttribute('data-theme', this.value)"> <option value="dark-slate">Dark Slate</option> <option value="light">Light</option> <option value="nord">Nord</option> </select>
4. Use in HTML
<button class="ds-btn ds-btn-primary">Primary</button> <div class="ds-card">Card content</div> <input class="ds-input" placeholder="Type here...">

Tailwind CSS

The design system works alongside Tailwind CSS. Use CSS custom properties in arbitrary value syntax.

Using tokens in Tailwind
<!-- Background and text colors --> <div class="bg-[var(--portal-bg-surface)] text-[var(--portal-text-primary)]"> Themed content </div> <!-- Borders --> <div class="border border-[var(--portal-border-default)]"> Bordered content </div> <!-- Accent colors --> <a class="text-[var(--portal-accent-primary)]"> Link </a>
Using design system classes
<!-- You can also use .ds-* classes directly --> <button class="ds-btn ds-btn-primary">Design System Button</button> <input class="ds-input" placeholder="Styled input"> <div class="ds-badge ds-badge-success">Success</div>
Combining both approaches
<!-- Tailwind utilities + design system tokens --> <div class="p-4 rounded-lg bg-[var(--portal-bg-surface)] border border-[var(--portal-border-default)]"> <h3 class="text-lg font-semibold text-[var(--portal-text-primary)]"> Title </h3> <p class="text-sm text-[var(--portal-text-secondary)]"> Description using design system colors with Tailwind layout. </p> </div>
